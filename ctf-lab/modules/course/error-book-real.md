## 2026-08-26 · backleak 外包事件（模式级，第二次）

- **卡点**：backleak 侦查中期（自己找到了 vi.php 和备份文件方向），未按协议带三行卡点回来找老师，直接把整道题交给另一个 AI
- **结果**：拿回 flag{test_flag}——测试假旗；真 flag 未拿到；外包 AI 的论据还有硬伤（^M 是 \r，是 Windows 换行特征，不是"Linux 的证据"）
- **根因**：卡住时耐心阈值过低 + 明知其他 AI 无摩擦直接给答案——"要答案"压过了"要过程"
- **关联**：昨天 fi8 看题解（第一次），今天整题外包（第二次）——升级了。模式：卡住->忍不住->走捷径->愧疚->坦白。这个模式若带进三年计划，是能杀死计划的东西
- **教训**：无摩擦=无学习；外包拿回的不只是假旗，还有空心化的首杀
- **规矩升级**：真题期间其他 AI 禁止用于做题（查资料、纠错可以，代做不行）；卡住的唯一出口是带三行（已知/已试/卡点）找老师——摩擦是学费

## 2026-08-26 · php-batch 首杀之战（正门记录）

- **战况**：无参数 RCE 鏖战一整天。提取链（localeconv/pos -> scandir+next('..') 列父目录 -> array_reverse+next 掏 flag.txt）全程学员自己装配；读旗段疲劳要答案时，**走了正门**（直接找教练、当面把质疑怼出来），没有外包其他 AI--backleak 事件后第一个大卡点，旧模式（卡住→外包→愧疚）被打破的证据
- **技术链**：正则 `(?R)` 只放行零参数嵌套（字面量物理禁） -> 指针家族取数组元素 -> 返回值安检（rsort 返 true 不进管线 / fopen 双参数+返 resource 被淘汰 / array_reverse 返数组过关） -> 读旗：highlight_file(end(getallheaders())) + 请求头走私 '../flag.txt'（fi5 投毒思想换装）
- **靶机事故**：题目部署漏旗（父目录为空），教练侧发现并补旗后才可解--链路对却扑空时，先怀疑靶子再怀疑自己
- **待办**：费曼复述 -> 自写速查条目（course/无参数RCE速查.md）-> 双路复盘（走私 vs chdir+dirname 洗衣路线）
- **补记（2026-08-27）**：费曼五问全过（Q1/Q4 教师补精确版）。速查表原定学员自写，三轮拒绝后改为**教练代笔**；代价 = 周一 8/31 闭卷变体复测（挪旗改名，禁看速查表与对话）。学员主张"靠练习记牢"被采纳，但"后面"必须落日历
