## 2026-09-07 · greatphp 战斗复盘四纠一缺（P2300 通关当日费曼）

- **战况**：旗已实锤（v2 include 通道），复盘复述骨架全对（禁令范围/三重门/弹药结构/工坊流水线/URL 交付全流程），四处精度问题 + 一处灵魂缺位
- **纠①"把 syc 当作函数执行"**：eval 把参数当代码稿编译，不是当函数调用；且 syc 传的是对象——eval 先拉 __toString 变形成字符串再编译（这半句正是题眼）
- **纠②排除地图漏一角**：0e 排除理由正确（魔术串写死装不下弹药），但数组路漏了排除——数组正是当天上午亲手用 php -r 审死的（md5 拒收退 NULL 过门、eval 强转 "Array" 语法死）。正确地图：0e 死于装不下弹药、数组死于 eval 吃不下，**双双阵亡才轮到 Error 对象**
- **纠③"先把 eval 关了"**：?> 关的是稿子里的代码模式，不是 eval 本身——eval 全程在跑，被喂了一篇"只有中段能动"的稿子
- **缺④灵魂缺位（补考已留）**：复述全程没解释**为什么两个 Error 能过三重门**——本体（code 1≠2 → != 真）与变形结果（消息相同 → 一字不差 → 指纹全等）的二分，外加同行出生（变形结果印出生文件:行号）。补考题：用自己的话讲清这对矛盾怎么同时成立
- **根因**：机制复述停在"工坊流水线"层（做了什么），未下沉到"原理"层（为什么有效）；与 L10 时代"按模板打"同款倾向的轻症复发
- **亮点记档**：开战首日独立排除撞库死路（"撞库后面怎么执行命令"）；上午自学六发 php -r 实验证完整个攻击原语；弹药换通道后独立完成上靶取旗
