端口：8085
规划：Phase 2-3（lesson-04 位置，XSS 先行完成后回补）

## 题目列表

| 路径 | 题目 | 考点 |
|------|------|------|
| /up1/ | 头像上传 | 无过滤直接传 webshell |
| /up2/ | 头像上传 v2 | 黑名单绕过（大小写/列不全） |
| /up3/ | 头像上传 v3 | 黑名单 + MIME 伪造 |
