## 1. 设计原则（五条，全部从性格反推）
========================================================

1. **微规则**：规则小到崩不了。每日唯一规则：开靶场前先抽 1 题（<=5 分钟）
2. **安全气囊**：每条规则自带破戒协议——"断了 != 完蛋，第二天只做最小动作 = 接上"。你的模式是破一次就全弃，所以规则必须自带续命条款；**不做连续打卡计数**（断签显示 = 崩盘仪式，对这种性格是毒药）
3. **双档能量**：平日档 2h / 超频档 4-6h / 崩溃档 5 分钟。不对抗性格，给性格修轨道
4. **AI 退场**：能力必须从 AI 手里一档一档赎回来（时间表见第 4 节）
5. **新坑记账**：想开任何新赛道先写进"新坑清单"排队，不立即开（发散型专用防坑阀）

## 2. 阶段计划
========================================================

### P0 点火期（现在 -> 开学，约 2 周）

```
① 还债：fi8 毕业考 / up-lfi+XSS 复盘 / si5~si10 闭卷重测（10 分钟）/ 抽题器首跑
② 真题首杀（黑盒协议：不看源码先打 45 分钟，卡死再读）：
   本地镜像 3 道，难度递进：qwbs8-oldapache -> phpems -> backleak
③ 薅战队（放养也得薅），问学长三件事：
   a. 今年比赛日历（省赛/国赛/新生赛报名时间）
   b. 队内有没有题库/往届附件/靶机资源
   c. 下一场比赛能不能带上我（哪怕打杂）
④ AI 退场一档生效：先猜后问（问 AI 前必须先说出自己的猜想，错的也行）
```
产出物：3 份**自己写的** mini writeup（AI 只批改不代写）

### P1 大二上（9 月 -> 1 月，学期档 2-4h/天）

```
主线 A：真题黑盒训练，目标 15~20 道
  来源：BUUCTF web 入门+基础区 / 本地镜像 / 战队队内题
  协议：黑盒 45 分钟才准看源码；每题 mini writeup；错误进错题本
主线 B：武器化作业，自己写 3 支工具（"武器化"深度目标的落地）
  第 1 支（9 月）：目录/敏感路径扫描器（requests + 多线程 + 字典）
  第 2 支（11 月）：payload 字典生成/变形器（大小写/注释/编码绕过自动化）
  第 3 支（12 月）：盲注脚本通用化（参数化目标/条件/停止符）
辅线：校内课 = 一鱼三吃（绩点 + 408 打底 + 安全原理）
  计算机网络/操作系统/数据结构 = 考研 408 四门之三，也正是安全深度缺的理论
  计算机网络课上到哪层，就回靶场抓对应的包验证到哪层
  （速查表里每个"为什么"，带到课堂去问老师/对答案）
  这三门从"及格万岁"升级为"认真学内容"：绩点回血 + 408 打底 + 原理补深
  打开方式（讨厌听课版，学内容 != 坐着听课）：
  签到作业平时分拿满（人到场可神游，实验课/习题课值得认真上）
  + 考点用自己的格式学（苏格拉底问答 / 抓包验证 / 做成速查）
  + 考前两周往年卷冲刺（冲刺型人格的主场）
英文：不硬上（PortSwigger 已否决）。需求驱动：遇到只有英文 writeup 的题，
  用"AI 翻译对照原文"法硬啃，不搞每日任务
```

**时间验算**：15 题 x 6h = 90h + 复测 5min x 120 天 = 10h + 工具写作 = 30h -> **130h**
供给：2h x 120 天 = 240h。**余量 45%，容得下考试周空转** ✓

**里程碑（1 月底验收）**：15+ 真题 / 3 支自写工具 / 1 场正式比赛（战队报名）/ 错题本 >=3 本 / AI 依赖降一档

### 大四瀑布流（日历替你排好了牌序，不用"决定"考不考研）

```
2028.07-08  大三暑假实习 -> 转正评估
```

每一级都是上一级的安全网：实习接不住有秋招 -> 秋招接不住有考研 -> 考研接不住有春招。
**唯一纪律："懒得考"只许发生在 offer 到手之后--之前叫弃考，之后才叫选择。**

**毕业验收（三牌结构，共用同一套积累，不冲突）**：

- 牌 C（考研）：初试分数定生死（不看绩点）；复试用比赛/SRC/工具补绩点短板 -> 研究所/大厂/更高平台

## 3. 质量阶梯（回应"题目质量不高"）
========================================================

```
L0 自建靶场  -> 退役：只做复习基底 + 出题练习模板（出题是最深的学习）
L1 本地 41 真题镜像 -> 现在（PHP 组 7 个先行，已分类）
L2 BUUCTF / CTFtime 往届题 / 战队题 -> P1 主力
L3 Vulhub 组件漏洞 / 云组件 -> P2 暑假
L4 SRC 真实目标 -> P2 起
```

- 自建靶场没白做：10 天把碎片串成了线，功成身退，**别再升级它**
- "深度不够"的根源不是题，是基础（编程+理论）——正被专业课+武器化作业两条线补
- 付费靶场不买：真题质量 > 付费靶场；付费平台卖的是路径不是质量，路径这份文件就是

## 4. 机制重设计
========================================================

**AI 退场时间表（四档）**：

| 档位 | 时段 | 规则 |
|------|------|------|
| 一档 | 现在 | 先猜后问：问 AI 前必须先说自己的猜想（错也行） |
| 二档 | P1 | 真题独立 45 分钟后才许求助；AI 只答具体问题不喂方案 |
| 三档 | P2 | writeup 全自己写 AI 只批改；工具自己写 AI 只 debug |
| 四档 | P3 | AI 只做翻译和查资料（工具箱形态） |

检验问题（每月一问）：上个月 AI 替我做的决定，这个月我能自己做吗？

**新坑清单（发散型防坑阀）**：新建 `course/新坑清单.md`
规则：冒出新赛道念头 -> 写进去（一行）-> 回到当前主线。每月底翻一次，P2/P3 排期时再捞

**复测微规则**：
- 每日唯一规则：开靶场前先抽 1 题（<=5 分钟，口述三行解法）
- 破戒协议（写在规则里）：断了不算完；第二天只做"抽 1 题"这一件事 = 接上
- 不做连续打卡计数
- 周日执行层：每周 1 道限时重打（20 分钟，重置后从头打穿）
