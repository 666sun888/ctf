# 黑盒开局速查 v2(没有源码的第一手)

> 场景:真实比赛题/真实站——没有源码、没有提示、没有题解
> 原则:先看懂"它是什么",再问"它会错在哪"
> 命令环境:**CMD**(curl.exe 是 Windows 自带;Linux 讲究的 curl 参数差别见第 3 节坑)
> 验证标注:✓(YYYY-MM-DD)=当日 CMD 实测;未标注 = 方法论/教材知识
> 2026-08-26 首用:qwbs8-oldapache 真题首杀;2026-08-30 v2 对齐(CMD 实测通过)

========================================================
## 0. 开局流程(前 10 分钟只做情报,不动手打)
========================================================

```
1. 看首页:这是个什么功能(登录/上传/查询/留言/...)
   -> 功能点 = 输入点 = 攻击面
2. 看指纹:猜技术栈(第 1 节)
3. 找输入点:URL 参数 / 表单 / cookie / 请求头,全列出来
4. 探路径:robots.txt / README / .bak 备份 / 常见后台(/admin /login)
5. 故意搞错:输入 ' 看报错 -> 报错是导航(黑盒版的读源码)
```

========================================================
## 1. 指纹速查(看什么 -> 猜什么)
========================================================

| 信号 | 猜 |
|------|-----|
| Cookie: PHPSESSID | PHP 系 |
| Cookie: JSESSIONID | Java 系 |
| 响应头 X-Powered-By / Server | 可能直接告诉你(✓ 本地靶场实测:Apache/2.4 + PHP/8.2 直接亮出) |
| URL 以 .php/.jsp/.py/.go 结尾 | 直接告诉你 |
| 404 页面样式 | 框架特征页 |
| F12 源码里的 generator/powered 注释 | CMS/框架名 |
| 浏览器装 Wappalyzer 插件 | 一键指纹(推荐装) |

========================================================
## 2. 输入点 -> 漏洞家族对照(你已经会的)
========================================================

| 看到什么输入点 | 想到哪个家族 |
|---------------|-------------|
| 查询/搜索参数 | SQL 注入(' 试错)、XSS |
| 登录框 | 字符串注入(免密 admin'# / 万能 ' or '1'='1) |
| 文件上传 | 传马全家桶 |
| 带文件名的参数(?file= ?page= ?path= ?img=) | 文件包含/路径穿越 |
| ping/回显类的输入框 | 命令注入 |
| 显示别人数据的页面(个人中心/订单/工单) | 越权/IDOR(P2 新家族) |
| User-Agent/Referer 被展示出来 | 头部注入点(xs/fi5 的老朋友) |

**开做前先答一句:这是哪个家族、动作是什么**(错题本立的规矩)。

========================================================
## 3. 探测命令速查 ✓(2026-08-30 CMD 实测)
========================================================

```
curl.exe -s -I http://目标/                                 只看响应头(指纹第一手,Server/X-Powered-By 直接亮栈)
curl.exe -s http://目标/ | findstr /i "href"                源码指纹(管道通;pattern 用英文)
curl.exe -s -o NUL -w "%{http_code}" http://目标/robots.txt 探路径,只回状态码(404=没有)
curl.exe -s "http://目标/?id=1%27"                          试错看报错(URL 编码的 ',别裸打)
```

**CMD 坑(2026-08-30 实测)**:
① **中文 pattern 匹配不上 UTF-8 页面**:GBK 控制台敲的"场景"两个字和页面里的 UTF-8 字节对不上,
   findstr 返回空——别误判"页面没有"。中文指纹改用 F12 肉眼看,findstr 只搜英文关键词(href/generator/powered)
② **% 的两副面孔**:交互式 CMD 里 %27、%{http_code} 原样安全;**写进 .cmd/.bat 批处理文件里,
   %2 会被当批处理参数吞掉(%27 变 7,URL 编码全毁),%{http_code} 的 % 直接消失**——
   批处理里一律双写:%%27、%%{http_code}(已实测:单写发出去的是 id=17,双写才是 id=1%27)
③ Windows 自带的是 curl.exe;裸打 curl 可能撞上 PowerShell 的 Invoke-Request 别名(老系统)或 Git Bash 的 curl(环境不同),
   认准 .exe 后缀最稳

## 4. 黑盒纪律(真题首杀协议)
========================================================

- **45 分钟内**:不搜 writeup、不问 AI、不翻题解——只有你和页面
- 速查表(含本表)可以开——方法论不是答案
- **记录每一手**:发了什么、回了什么(黑盒的证据链,复盘全靠它)
- 卡死 -> 写三行再求助:已知什么 / 试过什么 / 卡在哪一步
- 打完 -> `docker stop 容器名`(用完就关,别让漏洞机空转)
